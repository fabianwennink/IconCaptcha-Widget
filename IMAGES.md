Each round has one cake that looks like a real object, plus three real photos.
Files live in `images/round1/`, `images/round2/`, `images/round3/`:

| File        | What it is                                  |
|-------------|---------------------------------------------|
| `cake.jpg`  | The cake (the answer)                       |
| `real1.jpg` | Real photo                                  |
| `real2.jpg` | Real photo                                  |
| `real3.jpg` | Real photo                                  |

Rounds: 1 = lemons, 2 = watermelons, 3 = phones. All images are 600x600 JPGs.
To swap an image, replace the file and keep the same name.
Check the license of any photo you didn't take yourself before sharing the repo publicly.
