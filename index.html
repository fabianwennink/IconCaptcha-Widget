Osborn Security

A fictional security check that makes you solve one of five silly CAPTCHAs every time the page changes. Hackathon demo.

Download extension

Chrome only. Free. It reads, stores and sends nothing from the pages you visit.

Install in 3 steps

  1. Open the downloaded zip and choose Extract All (Mac: double-click it).
  2. In Chrome, type chrome://extensions in the address bar, turn on Developer mode (top right), click Load unpacked, and pick the goblin-chaos-extension folder.
  3. Open any website (or refresh one that's already open). The goblin appears.

Turn it off: click "Turn off everywhere" (Alt+Shift+G turns it back on), or switch it off on the extensions page.
Not showing up? Pick the folder that contains manifest.json, then refresh the page.
